Main findings

  • Linear probes on a model's internal state beat the model's own verdict at spotting wrong write-ups (AUC 0.86 against 0.79), but a control trained on labels shuffled within tasks did almost as well: the probes had learnt which tasks are risky, and within a task they added nothing.
  • A hidden instruction to bias the write-up without changing any number raised wrong conclusions from 22 to 55 of 180. A probe and a simple word-count classifier both caught it (AUC 0.95 within tasks), while checkers that judge correctness caught little.
  • Disclosure rules alone detected none of eight kinds of planted analytic error. Hosted reviewers caught every one when nothing was withheld and lost detection only under the strictest policy.
  • A prompt that makes the model record the study design before it writes reduced analysts' errors across three Qwen3.5 sizes, where a larger model added no consistent benefit. Qwen3.5 27B followed by a gpt-oss 20B checker met the release threshold on both sealed task sets.
